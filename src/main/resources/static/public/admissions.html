Application process

How to apply

The current public form shows programmes and academic years enabled for applications by the institute.

  1. Review the published programme catalogue.
  2. Complete the application form with your name and email, then select an available programme and academic year.
  3. Save the application number shown after submission; it is needed to check the application status.
  4. Return to the status-check form with the application number and the email used to apply.

Please note

Application is not portal enrollment.

Submitting an application does not create a student portal account. An administrator must accept and enroll an applicant first; the applicant then receives a username and one-time temporary password by email and must change it before using student services. Requirements beyond the fields in the current application form should be confirmed with admissions.

Applicant guide

Common questions

These answers describe the current application flow. Confirm entry requirements, fees, deadlines, and required documents with admissions support.

What information do I need to submit an application?

The form asks for your name, email, an optional phone number, an available programme, and the active academic year. These are the fields requested by the public form; they are not a complete statement of academic entry requirements.

How do I check my application?

Use the application number shown after submission and the same email address used on the application. The status form is available on the application page.

Does an application create a student portal account?

No. An administrator must accept and enroll an applicant first. The applicant then receives a username and one-time temporary password by email and must change it before using student services.

What are the entry requirements, application fee, and closing date?

These details are not published in the current public admissions data. Contact admissions support at +256 741 902525 to confirm current requirements, any applicable fee, and deadlines before applying.

Why can I not choose a programme or academic year?

The application form needs at least one active programme and an active academic year configured by the institute. If options are unavailable, contact admissions support.
