System Settings

Academic and Fee Administration

Academic years, campuses, faculties, departments, and programmes are managed in Academic Operations. Student fee records are created and reconciled in Finance.

Backup & Data Export

Automated database and upload backup health is shown in System Status. Downloading an export here is not a substitute for a verified backup.

CSV exports are separated by dataset to keep each file's columns consistent.

Email Configuration

Email delivery is configured securely on the portal host, not in this browser. Check the Email status on the dashboard after changing server settings.

For the Cloudflare/TiDB pilot, use Resend over HTTPS with a verified sender domain. Keep API keys in the private host environment file; never enter them here or send them in chat.
